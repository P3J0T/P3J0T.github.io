# P3J0T / notes

Minimal static GitHub Pages site for notes on self-hosted AI, security research, Awoki, and AI systems.

## Publish as a user site

Create a public repository named:

```text
P3J0T.github.io
```

Copy these files to the repository root and push to `main`. In GitHub repository **Settings → Pages**, set **Build and deployment → Source** to **Deploy from a branch**, then choose `main` and `/ (root)`.

The site will be available at `https://p3j0t.github.io/`.

## Publish as a project site

You can also use any repository name, for example `notes` or `awoki-notes`. Use the same Pages settings. The URL will then be `https://p3j0t.github.io/<repo>/`.

This site uses relative links, so both modes work.
